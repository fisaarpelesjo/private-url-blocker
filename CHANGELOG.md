# Changelog

## 0.1.1

- Reduced privileged tab access by replacing `tabs` with `activeTab`.
- Added explicit extension page Content Security Policy.
- Removed production source maps from `dist/`.
- Split extension build and test build.
- Added metadata validation.
- Added privacy policy and MIT license files.
- Improved import handling for arrays of strings and exported payloads.
- Added storage quota preflight errors for oversized sync payloads.
- Improved AMO source build documentation.

## 0.1.0

- Initial Firefox Desktop and Android extension.
- Domain and URL blocking.
- Popup quick block action.
- Options page management.
- JSON import/export.
- Backup and restore.
- AMO packaging support.
