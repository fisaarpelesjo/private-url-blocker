# Privacy Policy

Private URL Blocker does not collect, sell, transmit, or share personal data.

The extension uses the URL of the current page locally to decide whether navigation should be blocked. This check happens inside the browser.

The user-defined blocklist is stored in Firefox extension storage. When Firefox Sync is available for extension storage on the user's platform and enabled by the user, Mozilla may sync that extension storage through Firefox infrastructure.

Private URL Blocker does not:

- use analytics
- show advertisements
- load remote code
- send browsing history to developer-controlled servers
- send the blocklist to developer-controlled servers

Import and export features are user-initiated local actions.
